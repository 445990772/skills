# 平台 AI SVG 配图规范：E-01 视觉设计系统

本规范替代原有画图经验，适用于平台内 AI 生成的 SVG 业务配图的新增、重绘与审查。所有流程图遵循下列完整标准；非流程类业务图复用同一视觉语言与组件规格，保持其真实关系，不人为添加流程顺序。真实产品截图不重绘。

## 权威参考

参考素材：[告警中心 E-01 流程图](../assets/e01-reference.svg)。来源为学习工作区的 `物联网云平台/04-操作手册/03-告警中心/assets/E-01_设备异常智能告警流程_精修版.svg`。

只复用 E-01 的视觉语言与组件规范，不复制它的业务节点、告警术语、分区比例或连接结构。下述用户明确指定的参数优先于示例中的个别字号、圆角等历史取值。旧色板、正文等字号反算、其他画布尺寸及 3D 场景经验不再作为生成依据。

## 视觉风格与统一规格

采用浅色企业 SaaS 设计系统，面向正式中文产品文档。

| 用途 | 规格 |
| --- | --- |
| 画布 | 1920×1080 横向；SVG 的 width、height 与 viewBox 对应一致 |
| 字体 | Noto Sans CJK SC |
| 背景 | `#FAFCFF` |
| 主色 | 钴蓝 `#326CF4` |
| 主标题 | `#152642`，36px |
| 正文 | `#263A5B`，16px |
| 辅助文字 | `#6D7E99`，辅助说明 14px |
| 区域标题 | 25px |
| 步骤标题 | 23px |
| 节点标题 | 20px |
| 卡片浅蓝灰 | `#F6F9FE` |
| 边框 | `#DAE4F2` |
| 圆角卡片 | 16px |
| 步骤编号 | 统一直径 44px 的圆形 |
| 功能图标 | 同一套蓝色线性矢量图标，约 2px 线宽，统一容器尺寸 |
| 间距 | 8px 栅格体系，区域间距 24px，卡片内边距 20–24px |

同级字号、字重完全一致；标题层级可沿用示例的 700 字重、正文与辅助说明 400 字重。同类图标保持容器与绘制比例一致，按业务语义选择图标。

仅风险或告警状态少量使用暖橙色。禁止彩虹配色、大面积渐变、金属光泽、3D 场景或监控大屏风格。

## 排版与连线

- 以横向主流程为骨架，业务区域模块化分组；卡片对齐、纵向高度均衡。按实际内容分配区域宽度与内部布局，避免某一区域明显留白，不机械复制 E-01 的三栏比例。
- 清晰蓝色实线箭头表达主流程，虚线表达可选通知或辅助关系。箭头与连接标签不得穿过文字、卡片；预留独立连线通道，端点明确落到对应节点。
- 并行流程保持独立，仅在业务指定的汇聚节点合流；不得因复用线段暗示新增依赖、先后顺序或汇合。
- 底部可设置紧凑的处理完成与记录追溯区域，但仅呈现业务内容中已有的结果与追溯信息。
- 中文完整清晰，按词组换行，避免裁切、缺字、单字孤行。版面不足时重排区域、卡片和连线，不随意缩字、删内容或压扁画布。固定画布确实无法完整容纳时说明冲突并请求拆图决策，不擅自拆分业务。

## 业务保真

生成前整理流程标题、副标题、业务分区、节点与描述、连接关系与条件分支、最终状态及处理结果。重绘已有 SVG 时先提取原有业务内容，逐项作为核对基线。

严格保留用户提供的节点、标题、连接、分支条件、状态及先后顺序，不新增、遗漏或擅自更改流程。未提供的业务信息不得借用 E-01 内容补齐；缺失信息影响流程含义时先澄清。优先保证信息逻辑与可读性，其次才是装饰。

## 交付核查

1. 对照业务基线逐项检查节点、连接、条件、状态、顺序及并行汇聚，不仅检查文字是否存在。
2. 核验画布、色板、字体层级、圆角、编号、图标与间距符合本规范。
3. 渲染 SVG 检查中文、文字边界、箭头避让、卡片对齐、区域均衡及整体阅读顺序；批量修改时全量检查，不用生成成功代替视觉验收。
4. 在文档实际承载宽度检查显示与放大阅读；保持比例，必要时提供放大入口，不用旧的正文字号反算规则改写规定字号。若交付包含 PDF 或 Word，核查实际导出后的字体、箭头与裁切。
5. 检查图片引用和相关构建。区分技能规范更新、图稿改造与发布验证；仅修改 skill 不代表既有平台 SVG 已批量重绘。
