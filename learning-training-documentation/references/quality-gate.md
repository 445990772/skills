# 学习与培训文档质量门禁

## 用户可读性先检查

操作文档应让不懂实现的用户直接照做。逐篇检查入口、必要输入、选择条件、确认动作和可见结果；删除不影响当前操作的来源原理、内部边界、作者核验和重复说明。不要把难懂的长句仅拆成列表或搬进提示框。精简不能丢掉点击路径、重要后果、业务条件、图片和必要恢复入口。筛选依据见 SKILL.md 的“用户操作文档先让人看懂”。

## 按交付类型审查

从目标读者视角检查，逐项标为通过、失败或不适用。仅把适用且影响核心成果的问题作为阻塞。大纲按大纲验收，参考按参考验收，不能拿完整操作课的截图要求判断一篇理论文章。

通用操作手册按真实菜单与可复用规则验收，不要求课程案例或人为角色分册。用户明确要求的截图简版按入口、真实图片和简短图注验收，不要求完整业务闭环，也不能据此宣称未经测试的功能已完成验收。作者核查范围、未知项、阻塞和交付状态保留在证据记录与交付说明中，不进入通用操作正文；删除这些措辞不会消除证据阻塞。

完整操作手册按当前用户／项目已确认的结构检查，必要前置、动作、可见结果或相关风险缺失、界面手册正文无真实截图、关键步骤缺对应图片，均为交付阻塞，不能以“流程简单”“已有后续功能”或构建成功豁免。先按用途核准完整操作、纯展示、导航、FAQ、大纲及用户明确要求的截图简版，逐篇记录适用规则和结构约定；有实际操作的 index.md 也不能因文件名是目录入口而跳过。结果随步骤和图片呈现时，不因缺独立“结果验证”标题判失败或恢复章节；配置文档的功能验证仍按其用途检查。

| 范围 | 通过条件 | 核心失败示例 |
| --- | --- | --- |
| 所有交付物 | 类型、读者、范围和预期成果清楚。 | 把目录清单称为完整入门教材。 |
| 学习起点 | 必要概念与资源明确，前置有真实来源；初次使用的入口引导聚焦眼前动作。 | 当前课要生成的结果被要求提前存在，或在入门入口堆砌与下一动作无关的内部授权机制。 |
| 概念引入 | 首次关键使用时解释定义、关系、来源与适用边界。 | 新术语或角色无解释，读者只能猜。 |
| 知识顺序 | 跨功能资料库的节点有责任、输入与产出；执行依赖边有消费对象、条件和事实依据，独立分支并列，图与正文一致。 | 仅凭互链或同一场景串成必经链；阅读资料被当作环境已配置；归属未核实时宣称顺序已验证。 |
| 内容颗粒度 | 一篇有独立能力或任务，低信息碎片已合并。 | 每个菜单发布三行说明，缺少完整成果。 |
| 事实 | 来源适用、前提明确，已验证和待验证结论分开。 | 过期规则被写成当前事实，模拟结果冒充实测。 |
| 概述与导航 | 简洁表达目的；标题直接说明主题，用途或职责备注放概述引用块；操作入口写入首次进入功能的步骤；FAQ 外的关联资料默认位于文末“推荐学习”，链接和适用条件保留。 | 标题下单列菜单入口说明，营销话术取代学习目标，职责说明堆进标题，移动引用时丢失前置或链接。 |
| 课程／指南 | 路径、阶段成果和自测明确；完整课程有示范与迁移练习。 | 只有阅读列表或逐字照抄，没有能力检查。 |
| 概念课 | 定义、推理、例子与反例一致，可核对答案或判据。 | 省略关键前提，只写“显然可得”或“已经理解”。 |
| 软件产品操作手册 | 遵守当前已确认结构；前置、动作、可见结果和相关风险完整，正文真实截图覆盖关键界面步骤；注意事项与排障按职责组织。 | 套模板恢复用户已删章节，结果或风险缺失，空标题凑数，整篇只有文字或用入口图证明保存成功，或把作者逐字段审查写成读者动作。 |
| 操作／设计归属（软件产品） | 手册只保留真实可用操作；概念与详细规则归设计或原理参考，操作页保留影响选择的必要摘要；研发状态留在作者记录，客户确需的边界说明有具体范围和依据；迁移后入链、图片、索引与站点同步，目标入口、身份和动作能承接原指引。 | 操作手册保留“功能参考”边界区；把未授权或缺源码判为待开发；隐藏实现写成可执行教程；删除旧页却留下旧站点或错向链接；改链后仍让读者在设计说明中付款、提交或查看业务结果。 |
| 通用菜单目录 | 按指定环境、账号与项目核对真实菜单、详情按钮和应用内入口的层级与顺序；目录导航不重复建文档，迁出的操作保持真实归属。 | 用源码全量菜单代替目标项目，因无独立侧栏项误删真实子任务，仅凭 404 判功能不存在，或撤下上游教程后仍要求读者执行其菜单操作。 |
| 通用正文 | 写清主体、业务对象、动作与结果，使用填写要求和选择规则；能力介绍正面陈述已有能力及必要条件，不含特定取证项目、应用案例、作者验收范围或待核实状态。 | 无必要地围绕未开放或旧版变化介绍当前能力；抽象术语代替实际动作和对象，通用流程绑定取证应用，或把调查进度写给操作用户。 |
| 功能权限（适用时） | 目标产品实际存在的身份、开放或准入、菜单、动作和数据条件逐项核实，相同流程共用功能文档，确有差异才用概述引用块说明。 | 固定职责画像或其他产品的授权模型替代实际授权，改写丢失有效事实，合并时删除独立流程，或把菜单可见等同于全部操作和数据可用。 |
| 菜单显示／隐藏（适用时） | 实际授权与展示链路结合真实菜单结果、访问上下文和部署版本核对。 | 因账号未授权判定功能不存在，或凭源码猜测管理员绕过、固定菜单等部署根因。 |
| 产品展示／入口引导页（适用时） | 简短说明用途、可见信息和必要来源，直链实际操作文档；正文嵌入与目标角色、页面和状态相符的真实产品截图。 | 为没有录入或处理动作的页面硬写操作步骤、结果验证和注意事项，把汇总页写成配置入口，或因正文简短而省略产品截图、用文档站截图代替。 |
| 功能配置说明（适用时） | 每个消费者直链共享配置；参数表聚焦取值与来源，步骤能从真实入口完成，验证功能结果，FAQ 置于排查位置；代码依据和现场验收分开。 | 把源码默认值当成现场值、用 YAML 墙代替步骤、从隐藏入口虚构操作，或用进程就绪声称功能可用。 |
| FAQ 合集（适用时） | 问题与回答清楚分段，合集保留功能／症状锚点；不加推荐学习或功能点目录，必要链接就地放入回答；现象、检查、处理及具体复测完整。 | 重复站点目录或附加阅读清单，问题和回答挤成一行，改标题却未更新入链，编造页面错误，把知识问答套成故障四步，或复测只说“恢复正常”。 |
| 操作粒度 | 一摘要一个任务目标，复杂细节展开，简单动作合并。 | 为字数凑步骤，或用摘要长度删掉必要动作。 |
| 全篇可读性 | 有先后顺序用有序列表，并列条件、原因和注意事项用无序列表；混合关系合理分层，单一观点保留短段落，同类正文一致执行且事实无损。 | 分号串联多个步骤或事项，把长段搬进单个列表项，给独立条件硬编号制造先后，只改示范篇，或拆句时丢失取值和例外。 |
| 参数与输入 | 最小有效输入，表格承载重要比较和来源；已确认默认生效且无需用户处理的配置不设必做检查，调整或恢复写为可选分支。 | 强迫填全部可选字段或重做已满足的默认准备，表格只重复必填常识。 |
| 派生／引用数据 | 作者核实来源与规则；正文保留当前读者需要的用途、接收结果与纠正途径，消费者无需了解上游生成过程。 | 读者自己的计算缺前提或单位，或把他人生产、发布和配置工作交给消费者。 |
| 具体提供方 | 作者核实实际来源；正文按职责说明，消费者前置写谁已提供什么及使用位置，生产细节留在设计或证据层。 | 以泛称代替作者调查，强制消费者学习生产方入口，或将消费者本人需准备的数据无依据地说成已由官方提供。 |
| 失败与缺失条件 | 给出判断、补齐动作和返回点。 | 只有“联系管理员”“请自行排查”。 |
| 多角色流程 | 责任、身份来源、交出对象与接收方检查明确。 | 一个人的权限或页面被用来证明另一个人可操作。 |
| 只读取证（用户限定时） | 沿用既有对象与数据，核对页面进入和查询有无隐式业务写入；无法可靠避免时保留证据缺口。 | 为补截图新增数据，或把自动绑定成员、保存元数据、同步等当成只读查看；拦截写入后伪造成功状态。 |
| 实际执行 | 产物或行为满足标准，有适当证据。 | 只凭成功提示就断言下游功能可用。 |
| 学习资料库 | 目录按真实需要，依赖图与索引同步。 | 非软件课程被强制建立部署目录，空层级泛滥。 |
| 产品级体系（要求时） | 按真实产品范围核对定位、核心业务、使用与支撑等生命周期问题；重要领域有正文或明确缺口，学习导航尊重前置并优先业务成果。 | 只罗列现有菜单或少数功能就称全域覆盖，照搬其他产品承诺，把占位或规划当成已验证能力，或以管理支撑替代核心业务介绍。 |
| Markdown 文档站（要求 HTML 时） | 成熟引擎从 Markdown 构建页面与关系图，每篇发布文档可点击发现；页面、资源、锚点、搜索和图谱在浏览器可用。 | 同时维护手写 HTML 或独立图谱数据，隐藏首页或未编号正文，编辑器图谱被当作静态站图谱，容器可见但内部图形未渲染。 |
| 阅读交互（文档站） | 布局调整有需求依据；菜单与正文独立滚动，目录开关及定位顺畅；图谱存在时可放大并使用；长目录、矮窗口与窄屏实测。主题借鉴核实真实 DOM 与计算样式，不同主题和明暗色的表格、列表、高亮隔离正确。 | 固定套用某次尺寸或动画参数，把本地适配称为官方原样，主题规则串用，菜单滚轮被拦截或带动正文，图谱只有可见容器，或仅凭构建通过宣称交互正常。 |
| 标题与排序 | 默认显示标题不带排序序号；用户明确要求显示编号时按约定执行。去号保序有各层基线，实际排序字段贯通目录列表、浏览器侧栏与索引，首页、同值、未编号及无 index 文件夹均核对。 | 仅改 CSS 或 title，H1 与链接文字仍带号；只写元数据未接比较器，擅称支持 weight，或去号后中文排序改变原顺序。 |
| 迁移保全 | 入链、章节、附件、目录与当前索引同步；引用图片内容保留，共用附件按消费者处理；验证使用最新源和实际部署路径，原业务证据状态不变。 | 用旧快照覆盖并发正文或截图，工作区无差异就称链接可用，移图使另一篇失效，或以构建成功升级实操验收。 |
| 产品拆分（要求时） | 以目标读者、实际任务与交接结果判断归属；各产品工程可独立安装、构建和发布，正文与附件无需父工程或外部目录。 | 按“SaaS”字样分配客户教程，复制正文却共用外部依赖、软链接或输出。 |
| 客户发布边界 | 作者资料从实际启用的页面、目录、搜索、图谱与附件等输出中排除；客户所需内容已迁出并有有效入口。 | 仅隐藏侧栏或标记 audience，内部账本仍可访问或被索引；排除作者页时丢失客户操作。 |
| 快速入门归属 | 从必要准备达到首个成果的教程进入既有入门栏目；标题明确对象、动作及产品，复用权威手册与恢复入口。 | 入门混入运营供给流程，教程留在无关产品，或为整理内容机械增加／删除真实系统层级。 |
| 文档集成与 AI（要求时） | 计划基于现有能力与首批交付节点，维护与集成按真实依赖并行；展示状态与可信语料分开，检索引用和更新撤回可验证。 | 全量正文完工前禁止接入，固定某次人力与周数，可见占位被当作可信答案，或将计划写成已上线能力。 |
| 功能边界（适用时） | 每篇的前置、步骤、配置消费者、效果与验收属于其实际负责的功能或明确标注的条件分支；业务动作与内部术语有清楚映射。 | 因同属视频场景就混写配置，或只说“云端节点／流接收”而不说明读者实际要完成什么。 |
| 大纲 | 每节有目标、前置、主要内容、证据／练习计划及未知项。 | 虚构字段与操作，把骨架宣称为已验证教材。 |

约 50–80 字概述、约 50 字复杂操作摘要是中文操作文档的可读性参考，不是所有语言和交付类型的机械判分线。参数来源、原理说明与页面状态不应被编号成没有实际动作的步骤；这些格式要求要一致应用于全部适用章节。

### 操作文档与附件复核

编写、修订和核对时，按当前正文与最终交付附件逐项判断下表；在作者记录或交付说明中标为通过、缺口或不适用。已有证据只有在版本、对象、状态和文件仍匹配时才能复用。适用且影响核心结果的缺口阻止完整操作手册通过，不要求为不适用项造数据或执行未授权动作。

| 检查项 | 通过条件 | 缺口或失败示例 |
| --- | --- | --- |
| FAQ 归属 | 操作页用简短症状链接直达已有合集的具体锚点，完整回答只维护一处；必要恢复动作仍在步骤或恢复分支。 | 操作页重复合集 Q／A，链接只到合集首页，或归集时删掉必要恢复动作。 |
| 异步状态 | 区分加载中、查询失败与加载完成后无结果；空态结论限定当前账号、范围和条件。 | 未加载完就断言无资源，查询失败当空态，或据空列表判定功能不存在。 |
| 当前截图 | 按当前正文引用核对关键步骤覆盖及画面内容，换图或撤图后重判结论；裁剪仅证明保留区域。 | 沿用旧图计数与验收，图片可解码就判业务正常，或裁掉播放错误后声称播放成功。 |
| 最终附件 | 可下载、导入或执行的示例经清理修改后，按用途验证最终交付文件；下游动作有独立证据。 | 用修改前的成功记录代替最终文件验证，或以解析、导入成功证明设备控制、通知投递。 |

### 静态批量审查的口径

先明确当前发布内容根、排除目录、逐篇类型和各规则的适用分母；引擎、依赖、生成输出及作者资料不混入发布正文统计。完整操作手册、展示页、导航和占位按各自用途及已确认结构判断，不能因缺图或必要内容缺失反推为例外；也不以固定五节要求覆盖有效的结构约定。

自动扫描用于定位问题；“保存后重开、刷新、逐字段核对”等关键词命中只作语义复核候选。结合任务目标与实际行为，区分作者实现核验和读者确需完成的生效、查询或恢复动作，裁决后再修改，不按词批量删步骤。

分别报告格式与链接、正文配图与关键证据覆盖、产品入口及业务验收结论。有图片不等于匹配，移出不适用截图后按有效证据重新计数；结构零失败、零断链或构建通过不能消除未验证入口与业务结果缺口。没有新增产品实测时明确该边界，不用静态通过推导功能已验收。

## 证据审查

先选与主张匹配的证据，再检查其真实性和边界：

| 场景 | 需要核对 | 不能替代它的内容 |
| --- | --- | --- |
| 概念与理论 | 定义与来源、假设、推理、正确算例及反例。 | 只有结论，没有前提或可核对的依据。 |
| 命令／代码 | 环境条件、实际输入输出、关键产物和结果检查。 | 把预期输出声称为已执行记录。 |
| 软件界面 | 目标版本、真实角色、页面与状态，关键动作证据。 | 旧图、其他角色页面或模拟成功提示。 |
| 实体实践 | 规范来源、真实操作条件、观察或测量记录。 | 用示意图宣称物理实验成功。 |

每张图只证明可见事实。操作图检查页面定位、角色边界、输入／保存／错误等状态及对应步骤；概念图检查变量、关系、假设和文字一致性。证据中不泄露凭据或不应公开的个人与客户信息。

同页的独立功能逐项核对步骤和配图，不能以一张入口图覆盖全部标签。教命令查询时，图片须显示实际命令与输出；教网页访问或桌面连接时，区分输入表单、登录页和已连接结果。正文简短不能成为缺少必要操作和结果图的理由；用户明确只需表单图时，按该范围交付，仍保留真实连接结果的证据边界。

详情页的活动页签、条件子页签和对象类型按目标部署核对；未定位对应版本源码的功能保留缺口，不用其他模块的同名页替代。

客户操作图注简短描述控件和可见状态，完整证明映射留在作者记录。截图后重新核对页面、活动标签、账号作用域和状态；脱敏保留业务数字、状态与菜单。空列表、零曲线、错误回答或诊断状态不得作为业务成功证据，也不得据此推断未验证的配置错误。

每篇完整界面操作手册必须在正文展示真实截图，关键界面决策、权限、异常恢复及接收结果逐项匹配页面和状态。简单动作可以共享相邻图片，不能推导为整篇无需图片；不要求非界面学习配软件截图。图片存在或数量达标只证明形式，不证明业务结果，图号和步骤编号以能定位为准，不强制一一等号。

作者用截图、接口或持久化证据检查文档的事实准确性，不等于让读者在操作手册中重做这些核实；部署配置的加载与链路验证按配置任务保留。发现某篇把作者核验写成读者动作时，检查同范围其他操作页的步骤和结果说明，记录检查及修订范围，不能只修被指出的一段。

## 场景专项检查

网络／性能类配置与 FAQ 检查限制的生效层、协议、版本和条件；布局容量、主页面 HTTPS、上游协议不替代实际业务请求证据。复测条件可比，不能把某种传输的连接上限当产品固定容量。

### 概念、课程与学习指南

1. 复算关键例题或复核推理链，确认所有使用的前提已经说明。
2. 确认独立练习改变了会影响判断的条件，答案／判据与题目分开，未引入未教过的必需知识。
3. 对建议学习顺序，核实每个前置的必要性；反馈、复习与首次学习依赖不能混为一谈。
4. 资料的版本、来源和适用范围可信；外部来源无法核实时准确标为待核实。

### 命令、软件与实体操作

1. 从声明的起点检查基础路径，必要环境、材料、依赖和权限没有遗漏。可授权执行时验证关键过程；不可执行时标明未验证，不宣称已经完成实操。
2. 命令写出工作目录、输入、必要参数、输出与错误恢复；界面写真实入口和关键状态；实体操作写条件、材料及适用规范。
3. 软件字段以当前实际校验为依据，关系与状态以适用的界面、接口、代码或官方资料核实。多条件共同决定可用性时不省略关键条件。
4. 非用户输入的数据说明来源、规则、编辑边界与纠正入口，普通字段不堆砌无信息量的表格。
5. 有角色交接时同时检查提供方的就绪结果与接收方的可用结果。合并为“后续功能”的章节仍保留当前检查和重要失败处理。
6. 需要设备或真实页面的任务无法取证时，在作者记录和交付说明中将具体路径标为待验证，不把调查状态写入通用操作正文。理论材料不受这一实操门槛约束。
7. 演示账号、练习仓库和材料在已有授权范围准备，不将文档编写视作对外发送、付费或生产变更授权。
8. 通用手册不默认加入课程示例；同一流程不因管理员与成员称谓不同而复制。上游授权前置由真实权限链支持，并用消费用户接收的可观察结果表达。
9. 逐篇按当前已确认结构核对概述、必要前置、操作、可见结果、限制与风险；结果可以随步骤和图片呈现，不机械补独立章节。注意事项保留限制与后果，异常处理和 FAQ 按约定放入常见问题或恢复分支；后续功能说明交接。保留有效内容与锚点，不为凑模板删内容或恢复用户已删章节。
10. 对完整界面手册逐项记录“关键步骤／所需页面状态／正文图片／证明边界／验收结论”。检查嵌图能加载、图片紧邻步骤且图注准确；核对图片内容和目标角色，不以仅存在图片文件或任意一张图片宣称通过。缺少截图或关键证据时明确失败项与补采条件。

## 链接与成品检查

跨多篇的可读性重构在宣布完成前，逐篇覆盖约定范围的全部章节（含概述、前置、配置步骤、代码块后的说明、验收、FAQ、导航与设计正文）。检查分号长段和既有列表项是否仍塞入多个独立事项，按真实先后或并列关系选择有序／无序列表。记录检查范围与实际修改范围，说明保留短而完整段落的判断。改动列表后核对编号层级、代码围栏和原有条件／取值，并运行下述链接与格式检查；只通过结构或断链检查不能证明读者能按文档执行。

从单篇发现步骤职责、验证粒度或事实归属的系统性问题时，逐篇检查约定范围的同类文档及相应章节，记录审查数、实改数和保留项依据；不能只修被指出的例句便宣称全库完成。操作页的宏观结果验证、作者侧事实取证与配置文档的参数加载和链路核实分别检查，不相互替代。

1. 移动、删除或改名后核对索引、前置、后续、图片及锚点，同时更新适用的 JSON 索引、根导航与站点目录并重建站点。重复操作目录页的必要独有说明应迁出，具有学习价值的课程地图仍保留。只建立实际有内容的资料维度，不检查固定三个目录是否齐全。
2. 批量合并或删除前记录链接基线及旧文档到新章节的映射；目标文档和受影响入链必须零断链，全库不能新增断链，既有且无关的断链单列报告。检查链接指向的是相关功能与症状，而不只是锚点存在；核对消费者与配置说明双向匹配，避免无消费关系的泛化链接。
3. Markdown 文档运行 `ruby <skill-root>/scripts/check_markdown_links.rb <learning-root>`。脚本检查本地路径与标题锚点，非零结果逐条处理；模板中的示例路径需人工判别，不应为示例虚建目录。
4. 脚本不检查远程链接内容、事实准确性、链接的语义或所有 Markdown 扩展语法；这些按任务人工核实。含配置示例时按适用格式解析，并核对参数、默认值及条件依赖在迁移后仍完整。其他格式另做实际链接和版式检查。
5. 从读者视角走读一条完整学习路径：能解释或执行、能判断对错、失败时能恢复，无需讲师补充关键步骤。
6. 要求 HTML 站点时完成引擎构建及输出链接检查，在实际浏览器检查目录覆盖、搜索、图片、图谱后端和节点跳转；这些只证明文档站可用，不代替目标产品的账号权限与业务流程验收。删除手写旧页前确认独有正文已转为 Markdown，不误删引擎生成页面。
7. 非 FAQ 的推荐学习迁到文末时核对引用内容、条件和功能分组，去重只移除完全重复项；FAQ 移除推荐学习或重复目录时，把实际恢复所需链接放回对应回答，保留问题锚点、检查与复测。要求连续编号时同时检查序列、title、H1、可点击目录和原附件内容，必要时用一次性映射完成，不新增日常维护脚本。

## 交付判断

- **按请求完成**：交付类型符合要求，约定范围的全部文档逐篇通过适用核心检查；概念材料有可核对依据，完整操作手册标题与内容齐全，界面步骤与真实截图对应，关键实操声明有真实证据。不得用抽查、零断链或构建通过替代全量标题及截图覆盖检查。
- **草稿／部分待验证**：结构和内容可用，但在作者证据记录及交付说明中明确缺失的事实、环境、证据及影响章节，不把未验证部分称为已经完成，不往通用操作正文塞调查状态。
- **需要重构**：成果、起点或依赖不明，关键推理和动作缺失。回到教学约定与学习地图，不只润色文字。

如果用户只要求大纲、参考或未执行的示例，按该范围交付并标明性质；不因为没有完成未请求的课程或实操而把任务判为失败。

### 全文语义高亮检查

概述使用“概述”并简述本篇内容，标题下不单列菜单入口。`info` 按点陈述本篇实际身份、菜单、操作及数据范围差异；没有差异则省略，不使用问题标题加说明或配置教程。改写时逐项核对原有有效事实点，不能将功能准入、身份、动作和数据边界合并为泛化的一两句，也不强加其他产品的权限模型。

逐节检查全文，先筛选信息价值，再定高亮等级。删除常规必填、日期先后等已由页面明确校验的常识和重复提醒；普通来源、默认值、切换行为和能力边界回归正文。`warning` 只保留影响结果或安全的重要非显然风险，混合块只突出风险句；`error` 覆盖危险动作及造成核心功能不可用的严重配置错误，后果与恢复要求有事实依据。保留有价值的非紧急预防措施，不机械按否定词或标题批量高亮。非 FAQ 的深入解释集中到文末推荐学习；FAQ 的必要链接放在对应回答中。保留 Q／A 独立块、有效锚点及截图，并确认各主题正确显示。

精简前后核对仍适用的高亮事实和级别，不能保留提醒原句却误删标记；有效高亮消失时按源标记、生成块类型、计算样式定位原因。主题切换后检查颜色、图标、正文和折叠，降级或删除以内容价值和适用性为依据，不要求每篇同时出现三类。

中文紧邻链接时，加粗放在链接标题内，如 `[**编写标准**](authoring-standard.md)`，避免 `**[编写标准](authoring-standard.md)**中的规则` 被渲染为可见星号。验收检查文章中泄露的 Markdown 标记，不能只检查 callout 或断链。
